## 二、待决策项（发布前必须定）

2. **基础设施标识**：
   - 方案 A（推荐）：**域名保留**（那是项目自己的品牌），**服务器 IP 换成占位符**（`<your-server>`）——IP 会变、且暴露机房位置；
