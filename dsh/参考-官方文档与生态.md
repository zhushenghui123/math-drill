## 三、逐条对照我们的实现

### 已经对上的（不用改）

- 组合包形状：`dsh.bundle.patch` + `cordis.patch.yml` 一行 `insert`（按**包名**引用）+ `exports["./client"]` ✔
- `defineTool` 字段与 `output.{schema,render}` ✔（与官方教程逐字一致）
- `Config` 用 Schemastery + `apply(ctx, config)` ✔
- 监听 / 注册全部走 `ctx.effect(...)` 拿 disposer ✔
- 槽位选**追加型** `conversation.input.dock`（`list`），不碰 `single`（ADR-015 决策 6）✔
- 客户端产物是 `__ModuleLoader__.load({id, factory})` 包装、`require` 只落平台表内 ✔
- 宿主半边挂只读路由、浏览器侧只拿**已剥答案**的文本 ✔（lookatstudy 同款思路）

### 可以借鉴的（按价值排序）

1. **`dsh.client.immediately: true`** —— 状态条首屏即出，不必等 bundle 拉取（statusbar 与 lookatstudy 都用了）。
2. **工具卡片 `tool.call.toolview`**（keyed，key = 工具名）—— 让 `math_drill_today` 的结果在对话里是卡片而不是裸文本（**我们已有工具，接上就见效**）。
3. **`settings.section`** —— 把 `baseUrl` / 凭据路径搬进设置页，用户不必改 `cordis.patch.yml`。
4. **斜杠命令**（如 `/math`）—— lookatstudy 的 `/study` 是它面板的单一入口。
5. **`conversation.composer.dock` 的状态丸** —— 若状态条嫌占地方，可改成一行 `⚡今日 3/8 · 🔥连续 5 天`。

### 关键操作事实（今天踩过 / 差点踩）

- **装完插件必须重启 `dsh web`**：加载器图在进程启动时冻结（statusbar README 明写，我们实测一致）。
- **开发环不必装进 profile**：`dsh web --patch ./cordis.patch.yml` 直接用这一层，改完重启即可；装进 profile 是"交付"，不是"迭代"。
- **`$DSH_HOME/cordis.patch.yml` 是每台机器的共享覆盖层**（层序在 profile 自己的 patch 之后、`--patch` 之前）——用户做本机 override 的家（例如只在这台机器上换 `credentialPath`）。
- **patch 覆盖是整行替换 config**，不是深合并 —— 覆盖别人的行必须重述它需要的每个键。
- **`cordis_inspect_*` 是平台自带的"活体文档"**：`Slots.listSubTree` 直接给出槽位的 purpose/kind/scope/占用者/替换风险，`Service.listService` 给出真实方法签名。**以后写 UI 先查它，不要从源码猜**（那是我们昨天的老路）。
- ⚠️ **升级宿主 DSH 之前必须先做的一件事**（评审 Q12 提出）：`build/web-platform.ts` 的 `PLATFORM_MODULES` 是**快照不是契约**；若上游新版把某个平台模块移出/改名（例如社区插件声称 0.1.2-alpha 重组过客户端包），我们客户端半边的 `require` 会**当场抛错、状态条整块不出现且不降级**。⇒ **升级前对照上游 shell 种子表重取这张表**；若 `@deepseek-ai/dsh-client-ui-slots` 或 `@deepseek-ai/dsh-client-locale` 不在表内，依赖它们的 UI 做法要一并重估。
- **主题 token 的实测口径**（评审 Q7 要求写明）：`--dsw-alias-*` 在本机 0.1.1-rc.1 的计数取决于口径 —— **定义**（`ui-theme/src/styles/design-platform.css` 里 `--dsw-alias-*:`）**78 个**；**全部出现去重**（`src/styles/` 全目录，含注释与模板碎片）**80 个**。本文件此前写"79 个"是**不可复现的自陈数字**，已按两个口径改写。
- ⚠️ **不要在浏览器产物里 value-import 宿主半边**（评审 Z1）：宿主半边依赖 `@deepseek-ai/dsh-tools` / `schemastery`，浏览器那边一旦 import 它就会撞 purity 闸门。两边共用的常量放 `src/shared/`，**相对 import ⇒ 被 tsdown 内联**（2026-09-20 已实测：产物里仍只 `require("react")`）。
- **动态插件（cordis preset）是另一条路**：`cordis_define/run` 运行时定义插件、`cordis_inspect_self` 看诊断。适合**临时验证**；**我们的项目要版本化、入仓、可回滚 ⇒ 仍走静态组合包这条路**。
